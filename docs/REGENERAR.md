# Fuentes editables

Desde la raíz de la actividad, ejecute:

```sh
mkdir -p entrega
typst compile docs/informe.typ entrega/Informe-M2-Flota.pdf
typst compile docs/presentacion.typ entrega/Presentacion-M2-Flota.pdf
```

Las dos fuentes cargan el mismo diagrama. Los datos citados pertenecen a la ejecución guardada en logs/. Antes de reemplazar cifras, conserve los registros originales.
